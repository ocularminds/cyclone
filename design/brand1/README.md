# Cyclone design kit

Open `index.html` for the interactive studio. It works from a local file with its adjacent folders intact. Read `brief.design1.pdf` for the visual brief or `GUIDE.md` for implementation detail.

The proposed identity is **Calm Precision**, using the **Stillpoint** symbol. The kit includes Porcelain, Ink and High Contrast palettes; Manrope and Atkinson Hyperlegible Next; input and form patterns; access and spatial guidance; outlined logo exports; cover artwork; and shared tokens.

## Main files

| File | Purpose |
|---|---|
| `index.html` | Interactive design studio and control demonstrators |
| `brief.design1.pdf` | Nine-page visual design brief |
| `GUIDE.md` | Detailed UX and implementation specification |
| `tokens.json` | Colour, type, spacing, motion and XR geometry roles |
| `tokens.css` | CSS theme tokens for the flat preview |
| `contrast-report.json` | 39 measured opaque colour pairings |
| `VALIDATION.md` | Checks performed and their limits |
| `assets/` | Logos, icons, cover sizes and visual previews |
| `fonts/` | Font files, CSS and SIL Open Font Licences |
| `source/` | Original editable 3D cover scene with Three.js notices |
| `manifest.json` | File inventory and SHA-256 integrity hashes |

The browser controls are local demonstrations. They do not connect to an agent, enable real delegation, verify a signature or actuate machinery. The Cyclone application has not been changed by this design kit. The original review remains separately saved as `brief.review1.pdf` in the project root.

Artwork is an original design illustration, not an application screenshot. The wordmark lettering is outlined in the SVG exports; retain the supplied font licences when distributing the kit. Keep the vendor MIT notice with the editable source scene.
