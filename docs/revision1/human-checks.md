These are unperformed checks, not acceptance evidence. The working local/demo fallback is delivered.

  relay configuration through the existing secure configuration route. Run the four live proposals, a
  matching approval/dossier, wrong-hash/expired/refusal cases and permitted fixture export. A supported
  amendment API contract is still needed; merely enabling an environment flag cannot implement it.
- **H3:** connect a Quest 3 or 3S. Record model, OS/browser, release commit, room and seated height. Run the
  whole first shift with controllers off, then settings, amendment, early-release cancellation and ledger
  replay. Measure sustained frame times/thermal behavior against 60 fps minimum, 72 target. Capture the
  VR Glasses FoV crop and repeat native anchoring/real desk-edge veto in a second room, including a small table.
- **Unfamiliar-user check:** ask someone who has not used Cyclone to complete a fresh shift without coaching.
  Record time to first inspection/decision, every wrong turn, ability to discover settings and rationale,
  comfort/reach, and whether they distinguish rehearsal, permission, proof and execution. Record their
  listening assessment of the machine locations, risk pitch and cues. Do not count the automated run as this check.

  as permitted by the current competition rules. Publication and playback are verified. The repository's

  video does not establish device performance or confirm a completed contest submission.
